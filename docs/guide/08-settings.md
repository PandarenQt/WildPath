# Settings reference

World settings, under Game Settings → Configure Settings → WildPath. The GM sets them.

| Setting | What it does |
| --- | --- |
| Rules | Which edition's conditions and rules apply: 2024 (the default) or 2014. Takes effect after a reload. |
| Dice | How rolls are made: digitally, or with physical dice whose totals the roller types in. |
| Movement Measurement | Whether a turn's movement is counted as distance on the Scene or as grid spaces crossed. |
| Several saves at once | When many creatures save at once: one window for all of them, or every save rolled for you. |
| Players see the odds | House rule: players see their chance to hit and a target's chance to fail its save before acting. |
| GM may reroll monster rolls with players' inspiration | The GM may spend a player character's Heroic Inspiration to reroll a monster's d20. |
| Roll hit points on level up | Roll each new level's Hit Die, or take its average (the 2024 default). |
| Shove as a Bonus Action | Baldur's Gate 3's rule: Shove costs a Bonus Action instead of an Action. |
| High ground | Baldur's Gate 3's rule: +2 to attacks from 8 feet or more above the target, −2 from 8 feet below. |
| Carrying | The 2024 carrying capacity, the variant encumbrance, or off. Takes effect after a reload. |
| Level Advancement | By experience points (offered when a combat ends) or by milestones. |
| Offer 2014 core content, 2024 core content, supplements, Unearthed Arcana, third-party and homebrew content | Which sources' feats and subclasses the level-up dialog offers. |
| Fonts for languages | A font for a language its reader doesn't know, instead of its script (`dwarvish=Dethek`). Add the font files first, under Additional Fonts. |

Lists, tables and rows in the system's text use plain words. If something shows a raw key such as `WILDPATH.SOMETHING`, that's a bug; please note it.
